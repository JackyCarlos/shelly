# 🐚$ shelly
An easy, very basic shell implementation for learning linux operating system principles. Besides command execution shelly supports the following features:
- redirection operators like `>`, `>>` and `<`
- chaining commands with pipelining `|`
- basic shell builtins like `cd` and `type`
- job control features like appending an ampersand `&` to commands in order to put them in the background. Additionally shelly supports job control via builtins `jobs`, `fg` and `bg`

### how to run
simply run `make && ./bin/shelly` inside the repo and get to know shelly.
